■ Mac / Linux での始めかた

--------------------------------------------------
1. 置き場所
--------------------------------------------------
このZIPを展開すると「_reftool」というフォルダが出てきます。
PDFやスライドを入れているフォルダの直下に、そのまま置いてください。

  書類をまとめているフォルダ/
    ├ _reftool/          ← ここに置く
    ├ 教科書/            ← 中身は自由。フォルダ分けは何段でもかまいません
    ├ 論文/
    └ ...

_reftool の「親フォルダ」より下にある PDF・ppt・pptx が読み取り対象です。
ファイルは移動もコピーもしません(場所を記録して一覧にするだけです)。

--------------------------------------------------
2. 必要なもの
--------------------------------------------------
Python 3.11 以降。ターミナルで次を実行して、3.11 以上と出ればそのまま使えます。

  python3 -V

⚠️macOS に最初から入っている Python は 3.9 で、このアプリには足りません
   (実機で確認済みです)。3.9 と出た場合や見つからない場合は、次のどちらかで
   入れてください。どちらでも構いません。

  ・公式サイトから入れる(おすすめ・Homebrew不要)
      https://www.python.org/downloads/ を開き、macOS 用の最新版を入れる
  ・Homebrew を使っている場合
      brew install python

入れ直したあと、もう一度 python3 -V で 3.11 以上になっていることを確かめてください。
なお、最初から入っている 3.9 は /usr/bin/python3 にそのまま残るので、
他のソフトへの影響はありません。

--------------------------------------------------
3. 起動
--------------------------------------------------
_reftool の中の「Start.command」をダブルクリックします。

・初回だけ、必要な部品の取得に数分かかります(以後は数秒で起動します)
・黒いウィンドウにアクセス用のURLが出ます。ブラウザで開いてください
・止めるときはウィンドウを閉じるか Ctrl+C

▼「開発元を確認できません」「ブロックされました」と出たとき
  作者の署名(有料の登録)が無いため、初回だけ許可の操作が要ります。
  お使いのmacOSによって場所が違います。

  ・macOS 15 (Sequoia) 以降
      アップルメニュー → システム設定 → プライバシーとセキュリティ を開き、
      下の方までスクロールすると
      「"Start.command" は開発元を確認できないため使用がブロックされました」
      と出ています。その右の「このまま開く」を押し、
      指示に従ってパスワードまたはTouch IDで許可してください。
      そのあともう一度 Start.command をダブルクリックします。

  ・macOS 14 (Sonoma) 以前
      Start.command を右クリック(または control キーを押しながらクリック)して
      「開く」を選び、確認画面でもう一度「開く」を押してください。

  ・どちらも面倒なとき(確実な方法)
      「ターミナル」アプリを開き、次を打ってから半角スペースを1つ入れ、
      Start.command をターミナルの窓へドラッグ＆ドロップして Enter。
        sh
      これで同じように起動します。

▼「アクセス権がありません」と出たとき
  ターミナルを開き、chmod +x と半角スペースを打ってから、
  Start.command をターミナルの窓へドラッグ＆ドロップして Enter を押してください。

--------------------------------------------------
4. 最初にすること
--------------------------------------------------
画面の案内にしたがって「再スキャン」を押すと、ファイルが一覧に並びます。
続けて「メタ抽出」を押すと、PDFからタイトルやDOIを自動で読み取ります。

--------------------------------------------------
5. 同じ端末だけで使いたいとき
--------------------------------------------------
config.toml の host を "127.0.0.1" に変えて起動し直すと、その端末からのみ
開けるようになります(既定は同じネットワークの他の端末からも開けます)。

--------------------------------------------------
6. Windows との行き来について
--------------------------------------------------
フォルダごとコピーすれば、そのまま動きます。ただし「.venv」フォルダだけは
作られた端末でしか使えないため、コピー先では自動的に作り直されます
(初回起動が少し長くなるだけで、操作は要りません)。
