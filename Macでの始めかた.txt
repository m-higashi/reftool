■ Mac / Linux での始めかた

--------------------------------------------------
0. GitHubから手に入れる
--------------------------------------------------
このアプリをGitHubのページから入手する場合の手順です。
すでにZIPやフォルダをお持ちなら、この節は飛ばして「1. 置き場所」へ進んでください。

▼かんたんな方法(おすすめ・ソフトの追加は不要)

  1. ブラウザでアプリのGitHubページを開きます
  2. ファイル一覧の右上にある緑色の「Code」ボタンを押します
  3. 出てきたメニューのいちばん下「Download ZIP」を押します
  4. ダウンロードされたZIPをダブルクリックして展開します
  5. 展開してできたフォルダの名前を「_reftool」に変更します
     ※展開直後は「reftool-main」のような名前になっています。
       この名前のままだとアプリが読み取り対象を判定できないので、
       必ず「_reftool」に変えてください(先頭のアンダースコアも必要です)

▼gitを使う方法(更新を受け取りやすい)

  ターミナルで次を実行します。最後の _reftool を付け忘れないでください。

    git clone <リポジトリのURL> _reftool

  以降、最新版を取り込むときは次だけで済みます。

    cd _reftool
    git pull

  ※作成されるデータ(library.db・backups・.venv)は更新の対象外なので、
    取り込んでも読み込んだ内容や設定は消えません。

▼ZIPで入れた後に新しい版へ入れ替えるとき

  ZIPを展開し直したうえで、中身だけを上書きします(データは残ります)。

    rsync -a ~/Downloads/展開したフォルダ名/ ~/置いた場所/_reftool/

  library.db・backups・.venv は上書きされないので、そのまま使い続けられます。

--------------------------------------------------
1. 置き場所
--------------------------------------------------
このZIPを展開すると「_reftool」というフォルダが出てきます。
PDFやスライドを入れているフォルダの直下に、そのまま置いてください。

  書類をまとめているフォルダ/
    ├ _reftool/          ← ここに置く
    ├ 書籍/              ← 中身は自由。フォルダ分けは何段でもかまいません
    ├ 論文/
    └ ...

_reftool の「親フォルダ」より下にある PDF・ppt・pptx が読み取り対象です。
ファイルは移動もコピーもしません(場所を記録して一覧にするだけです)。

--------------------------------------------------
2. 必要なもの
--------------------------------------------------
Python 3.11 以降。ターミナルで次を実行して、3.11 以上と出ればそのまま使えます。

  python3 -V

⚠️macOS に最初から入っている Python は 3.9 で、このアプリには足りません
   (実機で確認済みです)。3.9 と出た場合や見つからない場合は、次のどちらかで
   入れてください。どちらでも構いません。

  ・公式サイトから入れる(おすすめ・Homebrew不要)
      https://www.python.org/downloads/ を開き、macOS 用の最新版を入れる
  ・Homebrew を使っている場合
      brew install python

入れ直したあと、もう一度 python3 -V で 3.11 以上になっていることを確かめてください。
なお、最初から入っている 3.9 は /usr/bin/python3 にそのまま残るので、
他のソフトへの影響はありません。

--------------------------------------------------
3. 起動
--------------------------------------------------
_reftool の中の「Start.command」をダブルクリックします。

・初回だけ、必要な部品の取得に数分かかります(以後は数秒で起動します)
・黒いウィンドウにアクセス用のURLが出ます。ブラウザで開いてください
・止めるときはウィンドウを閉じるか Ctrl+C

▼「開発元を確認できません」「ブロックされました」と出たとき
  作者の署名(有料の登録)が無いため、初回だけ許可の操作が要ります。
  お使いのmacOSによって場所が違います。

  ・macOS 15 (Sequoia) 以降
      アップルメニュー → システム設定 → プライバシーとセキュリティ を開き、
      下の方までスクロールすると
      「"Start.command" は開発元を確認できないため使用がブロックされました」
      と出ています。その右の「このまま開く」を押し、
      指示に従ってパスワードまたはTouch IDで許可してください。
      そのあともう一度 Start.command をダブルクリックします。

  ・macOS 14 (Sonoma) 以前
      Start.command を右クリック(または control キーを押しながらクリック)して
      「開く」を選び、確認画面でもう一度「開く」を押してください。

  ・どちらも面倒なとき(確実な方法)
      「ターミナル」アプリを開き、次を打ってから半角スペースを1つ入れ、
      Start.command をターミナルの窓へドラッグ＆ドロップして Enter。
        sh
      これで同じように起動します。

▼「アクセス権がありません」と出たとき
  ターミナルを開き、chmod +x と半角スペースを打ってから、
  Start.command をターミナルの窓へドラッグ＆ドロップして Enter を押してください。

--------------------------------------------------
4. 最初にすること
--------------------------------------------------
画面の案内にしたがって「再スキャン」を押すと、ファイルが一覧に並びます。
続けて「メタ抽出」を押すと、PDFからタイトルやDOIを自動で読み取ります。

--------------------------------------------------
5. 他の端末(スマホ等)から使う
--------------------------------------------------
スマホからも使いたい場合は Tailscale を入れてください
( https://tailscale.com/  個人利用の無料枠があります)。
自分の端末どうしだけをつなぐVPNで、社内LANやインターネットには
公開されません。

サーバーにするMacと、見たい端末の両方に入れてログインします。
あとはMacの Tailscale IP(例: 100.x.y.z)を使い、
スマホのブラウザで  http://100.x.y.z:8585  を開くだけです。
IPは Tailscale アプリで確認できます。
(config.toml の書き換えは要りません)

画面はスマホの幅に合わせて縦並びに変わります。

--------------------------------------------------
6. 誰が開けるか(合言葉はありません)
--------------------------------------------------
このツールにはログイン機能がないため、既定では接続できる相手を
「この端末自身」と「Tailscale経由」だけに絞っています。
同じWi-Fiにいる他の人からは開けません。

変えたいときは config.toml の [server] allow を書き換えて起動し直します。

  allow = "tailscale"  ← 既定。この端末とTailscaleのみ
  allow = "lan"        ← 同じWi-Fi/LANの端末からも開けるようにする
  allow = "any"        ← 制限しない

起動時のターミナルに、いま何が許されているかが表示されます。
※インターネットには公開しないでください。

--------------------------------------------------
7. Windows との行き来について
--------------------------------------------------
フォルダごとコピーすれば、そのまま動きます。ただし「.venv」フォルダだけは
作られた端末でしか使えないため、コピー先では自動的に作り直されます
(初回起動が少し長くなるだけで、操作は要りません)。
