# スクリーンショット置き場

`list.png`（一覧画面）と `detail.png`（詳細パネル）をここに置くと、
リポジトリ直下の README.md から参照されます。

README.md の冒頭にある次のコメントを外すと表示されます。

```
<!-- スクリーンショットを docs/screenshots/ に置いたら、下のコメントを外してください
![一覧画面](docs/screenshots/list.png)
![詳細パネル](docs/screenshots/detail.png)
-->
```

⚠️ **実際の蔵書が写った画面を置かないこと。** 書名や雑誌名がそのまま公開されます。
架空の資料だけを入れたデモ用インスタンスで撮ってください。
