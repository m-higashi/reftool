# スクリーンショット置き場

リポジトリ直下の README.md から参照しています。

| ファイル | 内容 |
|---|---|
| `screenshot-main.png` | 一覧画面 |
| `screenshot-detail.png` | 詳細パネル |
| `social-preview.png` | 共有リンクのヘッダー画像(1280×640) |

`social-preview.png` は `make_social.py` で作り直せます(スクリーンショットを差し替えたら再生成)。
GitHub は自動では読みません。**Settings → General → Social preview → Upload an image** で登録します。

⚠️ **実際の蔵書が写った画面を置かないこと。** 書名や雑誌名がそのまま公開されます。
架空の資料だけを入れたデモ用インスタンスで撮ってください。
